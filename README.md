## 📋 О проекте

**Ads-Manager** — это платформа для удобного планирования, управления и отслеживания рекламных кампаний. Проект предоставляет инструменты для организации рекламного процесса от идеи до запуска.

***

## 🗂️ Структура проекта

```
Ads-Manager/
├── .github/          # Конфигурация GitHub Actions и шаблоны
├── src/              # Исходный код приложения
├── web/              # Веб-интерфейс
├── CONTRIBUTING.md   # Руководство для контрибьюторов
└── README.md         # Документация проекта
```

***

## 🚀 Быстрый старт

### Требования

- Git
- Node.js / Python *(в зависимости от стека)*
- Актуальная версия браузера

### Установка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/TessEndGrad/Ads-Manager.git

# 2. Перейдите в директорию проекта
cd Ads-Manager

# 3. Установите зависимости
npm install   # или pip install -r requirements.txt

# 4. Запустите проект
npm start     # или python main.py
```
